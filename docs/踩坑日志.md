## 已知坑预警（参考项目及社区高频，大概率会遇到）

### [预警] 集群断电/非法关机后 HDFS 只读
- 现象：文件系统变只读，写文件报 `Operation failed`
- 处理：停集群 → 清理 `hadoop-*.pid` → 检查 safe mode → 必要时 `hdfs dfsadmin -safemode leave` / `-updateNodeIds`
- 经验：关机前先 `cluster.sh stop`，养成习惯；这个问题修好就是一段很好的面试故事

### [预警] Windows 开发 → Linux 运行：脚本 CRLF 报错
- 现象：bash 脚本报 `$'\r': command not found`
- 处理：仓库已加 .gitattributes 强制 LF；已拉取的旧文件用 `dos2unix xxx.sh`
- 经验：shell 脚本提交前确认 LF 换行

### [预警] MySQL 重装残留导致 Hive metastore 初始化失败
- 处理：彻底卸载（yum remove + 删 /var/lib/mysql + 删 /etc/my.cnf）后再重装
- 经验：动 MySQL 前先备份

### [预警] Kafka 小内存节点启动失败
- 现象：启动后立即退出 / JVM OOM
- 处理：kafka-server-start.sh 里 KAFKA_HEAP_OPTS 调小（-Xmx512m）
- 经验：4G 小内存节点上所有组件的默认堆内存都要重新分配（ZK 256M、Spark executor 1G）

### [预警] DataX 同步中文乱码
- 处理：reader/writer 显式 `encoding: utf-8`，MySQL 连接串加 `characterEncoding=utf8`
- 经验：同步类问题优先查两端字符集
