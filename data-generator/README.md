# data-generator — 模拟数据生成器

数仓无数据可算，需要自己造数据。两类生成器：

## 1. 业务数据生成器（写 MySQL）

- 生成用户 / 商品 / 订单 / 支付 / 退款等业务数据
- **支持按天批量回灌历史**（拉链表初始化、留存指标必需 3-6 个月历史）
- 技术选型：Python（faker + pymysql）或参考原项目 log-collector 的 jar 方案
- 关键：业务表保留 `update_time`，按它模拟增量更新

## 2. 行为日志生成器（写 JSON 日志文件）

- 模拟用户浏览 / 搜索 / 点击 / 加购 / 下单 / 支付事件
- 输出 JSON 到 `/opt/module/logs/`，由 Flume taildir 监听（断点续传）
- 字段结构（与 DWD 解析对应）：

```json
{
  "common": { "uid": 1001, "platform": "app", "province_id": 1, "ts": 1723104000000 },
  "page":   { "page_id": "home" },
  "action": { "action_id": "click", "item": 1001 },
  "ts": 1723104000000
}
```

## 建议数据量（本地练习，别追求大）

| 数据 | 量级 | 说明 |
|---|---|---|
| 用户 | 10w | 一次性生成 |
| 订单 | 10w/天 | 按天回灌 3-6 个月 |
| 行为日志 | 100w 事件/天 | 每小时滚动一个文件 |

> 面试点：能讲清「造数规则如何贴近真实业务分布」（用户活跃度、时段规律、品类偏好）就是加分项。
